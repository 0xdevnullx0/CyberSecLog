# CyberSecLog — Daily Cyber Threat Intelligence Briefing

An automated cyber threat intelligence aggregation and briefing system powered by **Claude AI (Opus 4.6)**.

Every day at a configured time, CyberSecLog:
1. **Collects** threat intelligence from multiple open and commercial sources
2. **Risk-ranks** all items using a multi-factor scoring model tuned for the financial sector
3. **Generates** a professional executive briefing via Claude with adaptive thinking
4. **Delivers** the briefing by email in rich HTML format

---

## Architecture

```
CyberSecLog/
├── main.py                   # Entry point: scheduler + CLI
├── config.py                 # All settings from .env
├── requirements.txt
│
├── collectors/               # Intelligence source adapters
│   ├── nvd_collector.py      # NIST NVD CVE API v2 + EPSS scores
│   ├── cisa_collector.py     # CISA Known Exploited Vulnerabilities (KEV)
│   ├── news_collector.py     # RSS feeds, HackerNews, GitHub Security Advisories
│   ├── otx_collector.py      # AlienVault OTX threat intelligence
│   └── mitre_collector.py    # MITRE ATT&CK Enterprise (cached locally)
│
├── analyzers/
│   └── risk_ranker.py        # Multi-factor risk scoring + categorisation
│
├── briefing/
│   ├── generator.py          # Claude claude-opus-4-6 briefing generation (streaming)
│   └── email_sender.py       # HTML email via SMTP
│
└── storage/
    └── database.py           # SQLite: deduplication + briefing archive
```

## Risk Scoring Model

Each intelligence item receives a **composite risk score (0–100)**:

```
risk_score = base_score × Π(applicable_multipliers)
```

| Risk Factor | Multiplier | Trigger |
|-------------|-----------|---------|
| CISA KEV (actively exploited) | ×2.5 | Item is in CISA KEV catalog |
| Zero-day (no patch) | ×2.0 | Keywords: "zero-day", "0day", "unpatched", "in the wild" |
| Remote Code Execution | ×1.8 | Keywords: "RCE", "remote code execution" |
| Supply Chain | ×1.7 | Keywords: npm, PyPI, dependency, typosquatting |
| Financial Sector | ×1.6 | Keywords: bank, SWIFT, payment, crypto exchange |
| Critical Vendor (Microsoft/Oracle/OpenSSL…) | ×1.4 | Vendor name in title/description |
| Ransomware | ×1.4 | Ransomware family mentioned |
| EPSS ≥ 0.5 | ×1.3 | High exploit probability |
| EPSS ≥ 0.1 | ×1.15 | Medium exploit probability |

**Base score** is derived from CVSS (CVSS × 10) or severity label when CVSS is unavailable.

## Briefing Structure

Generated by **Claude Opus 4.6** with adaptive thinking:

1. **Executive Summary** — threat level badge (CRITICAL / HIGH / ELEVATED / MODERATE)
2. **Critical Vulnerabilities & CVEs** — ranked table with CVSS, EPSS, affected products
3. **Active Threat Actors & Campaigns** — APT groups, ransomware operators, TTPs
4. **Financial Sector Threats** — banking trojans, payment fraud, crypto-targeting attacks
5. **Supply Chain Risks** — compromised packages, dependency confusion, vendor breaches
6. **MITRE ATT&CK Activity** — techniques observed, kill-chain mapping
7. **Advisories & Industry News** — notable stories from security media
8. **Recommended Actions** — prioritised, actionable guidance for the security team

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Configure

```bash
cp .env.example .env
# Edit .env with your API keys and email settings
```

Minimum required settings:
```
ANTHROPIC_API_KEY=sk-ant-...
EMAIL_FROM=you@company.com
EMAIL_PASSWORD=your_smtp_app_password
EMAIL_TO=ciso@company.com,secteam@company.com
```

### 3. Run

```bash
# Test the full pipeline immediately (generates briefing + sends email)
python main.py --now

# Preview collection & risk ranking without Claude call or email
python main.py --dry-run

# Start the daily scheduler daemon (default: 07:00 UTC)
python main.py

# Check status of last briefing
python main.py --status
```

## Email Configuration

### Gmail (App Password)
1. Enable 2FA on your Google account
2. Go to **Google Account → Security → App Passwords**
3. Generate an App Password for "Mail"
4. Set `EMAIL_PASSWORD=<app-password>` (16-character code, no spaces)

```env
EMAIL_SMTP_HOST=smtp.gmail.com
EMAIL_SMTP_PORT=587
EMAIL_FROM=sender@gmail.com
EMAIL_PASSWORD=abcd efgh ijkl mnop
```

```env
EMAIL_SMTP_HOST=smtp.office365.com
EMAIL_SMTP_PORT=587
```

## Extending the App

### Add a new RSS feed
In `config.py`, add an entry to `RSS_FEEDS`:
```python
RSS_FEEDS["MyFeed"] = "https://example.com/feed.rss"
```

### Add a new data source
1. Create `collectors/my_collector.py` with a `collect() -> list[dict]` function
2. Return items in the canonical schema (see `storage/database.py` for fields)
3. Import and call it in `main.py` → `run_collection()`

### Adjust risk weights
Edit `MULTIPLIERS` in `analyzers/risk_ranker.py`.
